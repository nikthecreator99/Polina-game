# Приключения Полины

Новогодняя игра-подарок для iPad: платформер, в котором Полина растёт от детства (глава «Зелёный») до взрослой жизни. Веб-приложение (PWA): открывается в Safari и ставится ярлыком на экран «Домой», работает без интернета после первого запуска.

## Управление

- Слева внизу: ◀ ▶ бег (палец можно вести, не отрывая).
- Справа внизу: большая кнопка прыжка (держи дольше, чтобы прыгнуть выше) и кнопка броска камня.
- На компьютере для проверки: стрелки или A/D, пробел для прыжка, X для броска, Esc для паузы.

## Запуск на компьютере

Нужен любой локальный веб-сервер (модули не работают через `file://`):

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Установка на iPad

1. Открыть адрес игры в Safari.
2. «Поделиться» → «На экран Домой».
3. Запускать с ярлыка: игра откроется на весь экран.

После обновления файлов увеличь `VERSION` в `sw.js`, чтобы iPad подхватил новую версию.

## Устройство

Без сборки и зависимостей, чистый JavaScript и Canvas.

| Файл | Что внутри |
| --- | --- |
| `index.html`, `style.css` | экраны меню, HUD, тач-кнопки |
| `src/main.js` | экраны, главный цикл, масштаб под экран |
| `src/game.js` | физика, героиня, камни, гуси, монетки, камера |
| `src/draw.js` | отрисовка фона (Зелёный, станция, электричка), тайлов и персонажей |
| `src/levels.js` | карты уровней в виде ASCII и подсказки-таблички |
| `src/input.js` | мультитач и клавиатура |
| `src/config.js` | имя, что бросает, одежда |
| `src/save.js` | сохранение монеток и прогресса в `localStorage` |

### Как нарисовать уровень

Карта в `src/levels.js`, одна клетка = 48 px:

```
#  земля       =  доска (запрыгнуть снизу можно)   B  ящик (ломается камнем)
o  монетка     ~  лужа (минус жизнь)               E  гусь
C  чекпоинт    P  старт                            F  финиш (станция)
```
